## 问题

`/dataset`（evaluation.philoai.xyz）被用户判为「繁琐、色彩审美差、两边留空白」，而它**跑过** `web-visual-system`
并拿到 10/12 = 0.833「system present」的绿灯，据此施工。同条件成对实测（1600×1000、未聚焦、同一次运行）：

| 页面 | validator pass rate | 该 skill 的判读 | 用户的判断 |
|---|---|---|---|
| artifacts.philoai.xyz | 11/12 = 0.917 | system present | 满意 |
| news.aiplanet.live | 0.417（`chosen-references.md:37`） | **NO SYSTEM · 已记为不合格参照** | **满意，且是他主动点名的参照** |
| evaluation /dataset | 10/12 = 0.833 | system present | **不满意** |

**读数与用户满意度反相关**：给不满意的页开绿灯，同时把用户满意的两个参照之一判成不合格。
且它**确实**查的那几项，坏页面全面胜出——motion coverage 440/440 = 100% vs 79%；tabular numerals 65/65 vs 2/2。
它不是沉默，是给出反向信号。

根因不是「指标太工程化」，而是**作用域到 token 层就停了**：用户抱怨的每一件事都住在参数之上——
构图、用量（同一个 danger 角色刷了 1467 次）、页面的形态原型。上一轮把参数决定得**对**
（闭合间距梯、带嵌套规则的圆角族、按中文取的 13/22 行高、`--measure:56em`），页面仍然是坏的。

## 标定（本 ADR 的承重证据）

用户先裁「先做标定，再带判定交付」。候选检索按 `evidence-sufficiency.md`「发现候选的检索」执行：
品类从功能句推导、X 预言 `Vega-Lite`、三轮换三条轴。**三轮每轮都带出新子家族、未收敛**，
`Vega-Lite` 始终未出现——名单的代表性因此**不被宣称完整**。9 个公认高水准页面 + 3 个已知点，同一把尺：

| 候选判据 | 标定结论 | 反例 |
|---|---|---|
| 色相桶数少 = 好 | **证伪** | IBM Carbon 8 桶、AWS Cloudscape 9 桶，均高于被判差的 arena 改前（6） |
| 饱和色值数少 = 好 | **证伪** | Cloudscape 100 种 |
| 描边样式种类少 = 好 | **证伪** | Plotly 15 = arena 改前 15 |
| 描边密度低 = 好 | **证伪** | artifacts 21.8 ≈ arena 改前 25.6，而 artifacts 是用户最满意的那个 |
| 区域填充率 | **证伪**（更早一轮） | 54% 来自**有意且正确**的 `--measure:56em`；病在容器宽度不在 measure |
| 宽度认领 | **三种口径全部失败** | `<main>` 容器盒 5/5 退化成 1.000；通用 ink 并集把 arena 改前读成 0.975（通栏告警条顶满）；扫描线口径 arena 改前 0.703 **夹在 news 0.677 与 Cloudscape 0.762 之间** |
| 药丸/徽章数 | **只成立到"极端离群"** | 好页面 0–48，arena 改前 1767。48 与 1767 之间**无样本**，给不出边界 |

## 决策

**L1「用量」层不提供任何跨页阈值判定，只做两件事：**

1. **相对参照的极端离群检测**：某一类重复视觉元件（药丸/徽章一类）达到参照同类读数的 **≥10×** 时报警。
   它宣称的**只是**"这是相对该参照的极端离群"，不是"这个页面不合格"——这是数据唯一支持的形态。
2. **读数与参照并排 + 强制作者逐项作答**：其余读数照报，与参照的同一读数并排；每一项差异要求作者
   写一句「为什么这里不同」。**不写则退出码为「未完成」，不是「通过」。** 判定留给人，"必须答"由程序保证。

**L0 形态原型**排在所有 token 决策之前（document / workbench / feed / dashboard），有参照时直接取参照的形态。
**L2 参数**沿用既有 `web-visual-system` 全部内容，**一字不改**——它没有被证伪，只是不够。

**参照资格按层判定**（`chosen-references.md` 条目格式随之改）：一个页面完全可以「构图与克制值得抄、
token 卫生一塌糊涂」。news 就是：L0/L1 合格、L2 不合格（0.417）。旧的整体资格判定把它整个判掉，
**不是用户看错，是资格判定的粒度错了**。

## 被否决的备选

| 备选 | 否决理由 |
|---|---|
| 以参照实测值为跨页目标/上界 | 被自己表里的数打回：`bordersPer100` 改后 2.6、参照 21.3——向参照看齐就得**把描边加回去** |
| 保留四项"可迁移"判据 | 三轮评审 + 标定逐条证伪，见上表 |
| 只改 SKILL.md 散文、不建程序 | 同一段量法被散文写错过 4 次（`web-ui-observation.md:46`）；本轮又新增一例：普查脚本在未渲染页上报「2 色 / 14 描边盒」，与"极其克制的设计"读数逐字同形 |
| 把这层加进 `design-critique` | 本次失守在**生成侧**（调的是 web-visual-system、拿到绿灯后施工），判断侧的 skill 拦不住已拿绿灯的流程。用户已解除 2026-08-19 的边界限制 |
| 再花一轮做更大标定 | 摆给用户后他选了当前方案；且"哪个是数据区"本身是人工判断，评审已质疑它只是把未校准换个地方藏 |

## 作用域

- 结论作用域：**桌面宽视口（≥1440）**。移动端窄视口未测。
- L1 的离群闸**相对参照**成立，不含任何绝对阈值；无参照时它不产出判定，只产出读数与待答项。
- L0 的四种形态中，只有 document 与 workbench 有本次的前后实测支撑（`/dataset` 一例）；
  feed 只有横向样本（news），dashboard **零样本**——两者在 skill 里标为未验证、不给判据。
- 探针只量**呈现形式·关系/结构层**。内容对读者有没有用归 `web-ui-observation.md`「交付前的最低证据·一」
  与 `page-repetition`；信息架构与认知负荷归 `design-critique`。

## 已知未验证项

1. **离群倍数 10× 未标定**：它取自"好页面 ≤48 vs 1767"这一个负例，48–1767 之间无样本。
2. **候选名单未收敛**：三轮换三条轴仍出新名字，`Vega-Lite` 未出现。上表"好页面范围"因此不得当作总体分布。
3. **「作者必须作答」只验非空**：程序能证明材料齐了，证明不了解释成立。
4. **本 ADR 的产物尚未在第二个页面上用过**：只有 `/dataset` 一次前后对照。
5. **改后页面未经人眼核验**：截图工具在作者本机整体挂死（已用参照站做阳性对照确认是仪器故障），
   全部读数来自 `agent-browser eval`。
