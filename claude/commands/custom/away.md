# away

用户离开了。**这件事你观测不到**——没有任何读数能区分"他正盯着屏幕"与"他走了六小时"，所以只能由他告知。时长是估计值，不是硬期限；到点没回来照常按本模式走。

**本模式不消除等待**：需要他裁决的事仍然等他回来。它只保证等待期间在飞的产出被接住、且不依赖那个答案的活已经推到底。

## 生效期间

| 做什么 | 为什么 |
| --- | --- |
| 攒下的问题**一律不在离开期间发出**，留到解除时一次交出（唯一出口是下面那条例外）。`CLAUDE.md`「Surface Choices」那条「不依赖答案的活做完了就问」**在本模式下不适用**：它给的理由是"那之后的等待什么也不省"，而在这里那句不成立——发出去的等待要吃掉整个离开窗口 | 在这里发出去，回合就死在那儿，剩下的离开时长全部空耗 |
| 每推迟一个问题，当场往下面那处标记追加一行：**问题 · 它挡住什么 · 推迟时刻** | 不落盘的清单，几小时后只能靠回忆重建；也让「攒批」「没替他裁决」变成可核的 |
| 长跑的守望按 `~/.claude/references/background-agent-monitoring.md`「等待器的判据与上界」办；本模式只加一条：**守望的到期时刻必须晚于作业本身**，并把该上界写进下面那处标记 | 守望比作业先到期 = 后半程无人接手 |
| 把「away 生效中 · 起始时刻 · 预计时长 · 待答清单 · 怎么解除」写进本 session 已有的台账 / handoff；**都没有就新起一处**。「怎么解除」那一项照抄下面「解除」**整节**，再补一句「时长到点不算解除」——那条在正文首段，不在该节里 | 上下文压缩会清掉本命令的正文，那处标记会成为唯一权威。只写怎么进、不写怎么出，压缩后读到的就是一个没有出口的模式；而标记里同时带着起始时刻与预计时长，算得出到期时刻——「到点＝解除」是此时最省事的读法，也是最贵的 |
| 活全部推到底、只剩攒下的问题时，按 `background-agent-monitoring.md`「watchdog 唤醒时先判谁会去看结果」的**等人分支**收尾 | 那一支已定义好：有新事实才汇报，没有就只巡检不汇报，静默那种也要留一次打点 |

**例外——判据是代价，不是时机**：不立刻问、答案就会作废或让一段昂贵工作白跑时，立刻问。**"这件事正在进行"不是判据**（它几乎总成立）。两种都算：正门禁着一个已在进行的动作（要不要中止这次跑、这批要不要作废），以及**尚未开始的昂贵决策**（这批五小时生成用哪份基线、发哪一版）——后者最容易漏，因为上面那条"把不依赖答案的活推到底"正把你往它里面推。**推到底不含那一步本身。**

一个反向例外，**但它有条件**：疑似挂起时，`background-agent-monitoring.md`「卡死处置」要求发一次 `AskUserQuestion` 让用户拍板（`CLAUDE.md`「Surface Choices」的例外清单也逐字点了它）。本模式**只在能读出硬 deadline 时**覆盖它——去读那个数（wrapper 的 `CODEX_TIMEOUT` / 包裹脚本里的那个），**读得出且早于你预计回来的时刻**，就记进清单留到解除；**读不出、或晚于**，按上面的例外立刻问。别把"该套 deadline"当成"已经套了"：那一节是义务不是既成事实，而 wrapper 的默认总时长是 6h，与一次离开窗口同量级。

## 不做

**不替用户裁决。** 既不代答已经提出的问题，也不因为"现在问不了"就选一条默认路往下走——后者不留任何提问痕迹，事后从 transcript 里也认不出来，而后果一样。同理，长跑失败后**原因未定就不要自行续跑**：那是一次昂贵重试，归上面的例外。分不清该不该走，就停在那里记进清单。

要自动采纳推荐项是另一套机制：上游配置有配套的 `/custom:autopilot`（授权与记账含审计日志都在它那里，本命令没有），**本仓未收录**——需要代答能力时从上游获取，且注意两者不要同时开：本模式压住提问的发出时刻，而 autopilot 的代答挂在上游的 `PreToolUse | AskUserQuestion` 入口上（分支在上游版 `ask-recommend-gate.js` 内；本仓的该 hook 不含此分支），问题不发出、代答就永远不触发，grant 静默失效。

## 解除

**收到用户的新指令或答复即视为他在场**（后台回调、`Monitor` 唤醒、hook 注入的那些不算——本模式生效期间必然有这类输入）——当回合先说一句「away 已解除」，交出那份待答清单与期间的进展读数，并往标记**追加**一行「away 已解除 · 时刻」。**追加，不是改写**：那份逐条攒下来的推迟清单要留着给你对账。他明说仍不在时才继续。
