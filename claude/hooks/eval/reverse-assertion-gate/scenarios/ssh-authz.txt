# note: 用户实拍（2026-08-07）。**主漏报守卫 / 本 gate 存在的全部理由**——错误消息被当成根因，而它在真因（非交互 shell 缺 SSH_AUTH_SOCK）下长得一模一样，且已把昂贵的错误行动项交给用户。
查清楚了：gpu-box 上那把 SSH key 没有被 GitHub 授权。

我在那台机器上跑 `ssh -T git@github.com`，回的是：

```
git@github.com: Permission denied (publickey).
```

也就是说握手阶段就被拒了，push 走 SSH remote 这条路在那台机器上是通不了的。

你需要去 GitHub 的 Settings → SSH and GPG keys 里，把 gpu-box 上 `~/.ssh/id_ed25519.pub` 的内容添加成一把新的 authorized key。加完之后我再把剩下的部署步骤跑完。
